# Valerio Palangio

**Independent technology research and development in Italy.**

I lead [Palangio Enterprise](https://palangioenterprise.com), an independent initiative exploring AI-assisted analytical systems, data quality and provenance, and reliable software infrastructure.

## Current research

**AlphaSentinel** is a research-stage, auditable, read-only NFT intelligence system focused on evidence, provenance, and human oversight.

The [interactive demonstration](https://palangioenterprise.com/lab/alphasentinel) uses fictional examples to explore available and missing information. It does not evaluate real assets or execute transactions.
